개인정보 처리방침

시행일: 2026년 6월 22일

ClipShot(이하 "본 앱")은 Windows에서 화면을 캡처·녹화하고 보관함에 정리하는 데스크톱 앱입니다. 본 앱은 사용자의 개인정보를 최소한으로만 다루며, 캡처·녹화·보관함 데이터는 모두 사용자 기기(로컬)에 저장됩니다. 본 방침은 본 앱이 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 핵심 원칙

  • 계정·로그인 없음 - 가입이나 로그인 없이 설치 후 바로 사용합니다.
  • 로컬 저장 - 캡처 이미지, 녹화 영상·GIF, 보관함, OCR 결과는 모두 사용자 PC에만 저장되며 외부 서버로 자동 전송되지 않습니다.
  • 광고·추적 없음 - 광고, 사용자 추적, 행동 분석을 하지 않습니다.
  • 자동 전송 없음 - 진단 정보는 사용자가 직접 전송에 동의한 경우에만 외부로 전송됩니다.

2. 기기에 저장되는 정보(로컬)

본 앱은 다음 정보를 사용자 기기 내부의 앱 데이터 폴더 또는 사용자가 지정한 저장 위치(예: 사진 폴더, 사용자가 직접 선택한 폴더)에 저장할 수 있습니다.

  • 캡처 이미지, 녹화한 동영상 및 GIF
  • 보관함 정보 - 캡처 제목, 생성 일시, 타입(이미지/동영상/GIF), 캡처 출처 앱 이름(확인 가능한 경우), 이미지에서 추출한 텍스트(OCR, 본문 검색용)
  • 앱 설정 - 단축키, 표시 언어, 테마 등

위 데이터는 모두 사용자 기기에만 저장되며 외부로 전송되지 않습니다.

3. 화면 캡처와 텍스트 추출(OCR)

  • 캡처·녹화는 사용자가 단축키나 버튼으로 직접 실행할 때만 동작합니다. 백그라운드에서 화면을 몰래 기록하지 않습니다.
  • 이미지 속 글자 추출(OCR)은 Windows에 내장된 OCR 기능을 사용해 사용자 기기에서 처리됩니다. 캡처 이미지나 추출된 텍스트가 외부 서버로 전송되지 않습니다.

4. 진단·피드백 정보(사용자가 직접 보낼 때만)

오류 해결과 앱 개선을 위해, 사용자가 직접 전송에 동의한 경우에 한해 진단 정보를 보낼 수 있습니다. 본 앱은 진단 정보를 자동으로 외부에 전송하지 않습니다. 앱은 오류 진단을 돕기 위해 사용자 기기에 로그 파일(ClipShot.log, panic.log)을 생성할 수 있으나, 이 로그는 사용자가 직접 전송에 동의하기 전까지 기기 밖으로 나가지 않습니다.

전송 경로는 다음 두 가지입니다.

  • 설정 > 프로그램 정보 > "피드백 보내기"에서 의견(선택)과 진단 로그(선택)를 직접 첨부하여 전송
  • 앱이 비정상 종료된 뒤 다시 실행될 때, 직전 오류 기록을 보낼지 1회 묻는 안내(사용자가 동의해야만 전송)

전송에 동의한 경우 다음 정보가 포함될 수 있습니다.

  • 앱 버전, 운영체제 아키텍처(예: x64), 표시 언어(한국어/영어)
  • 사용자가 직접 입력한 의견
  • 사용자가 첨부에 동의한 경우, 앱 로그(ClipShot.log)와 오류 로그(panic.log)의 최근 일부

개인정보 보호: 로그를 보내기 전에 사용자 계정명과 사용자 폴더 경로를 자동으로 가립니다(****로 마스킹). 캡처한 이미지·동영상·GIF, 보관함 원본 파일, OCR 결과는 진단 정보에 포함되지 않습니다.

전송·보관: 위와 같이 사용자가 직접 보낸 진단 정보는 HTTPS로 암호화되어 전송되며, Cloudflare Workers KV에 저장됩니다. Workers KV의 특성상 데이터는 Cloudflare의 중앙 저장소 및 전 세계 데이터센터(글로벌 네트워크)에 저장·캐시될 수 있습니다. 서버에 저장된 진단 제출물은 Workers KV의 만료 기능에 따라 저장 후 90일이 지나면 자동으로 삭제됩니다. (이 자동 삭제는 서버에 보관된 진단 제출물에만 해당하며, 사용자 PC에 저장된 캡처·녹화·보관함과는 무관합니다.)

전송된 진단 정보는 오류 진단과 앱 개선 목적으로만 사용하며, 광고·프로파일링·제3자 판매에는 사용하지 않습니다.

5. 업데이트 확인

본 앱은 최신 버전을 확인하기 위해 업데이트 서버에 접속할 수 있습니다. Microsoft Store 버전은 Microsoft Store를 통해, 직접 다운로드(.exe) 버전은 본 앱 배포 서버(clipshot-website.pages.dev)를 통해 업데이트를 확인합니다. 이 과정에서 사용자의 캡처·보관함 데이터는 전송되지 않습니다.

6. Microsoft Store를 통한 설치

Microsoft Store에서 설치한 경우 설치·다운로드·업데이트는 Microsoft가 처리하며, 이에 대해서는 Microsoft의 개인정보처리방침이 적용됩니다.

7. 제3자 제공 및 처리위탁

본 앱은 사용자의 캡처·녹화·보관함 데이터를 제3자에게 제공·판매·공유하지 않습니다.

다만 사용자가 직접 전송한 진단 정보(4항)의 저장·운영을 위해 아래와 같이 인프라 사업자에게 처리를 위탁합니다.

  • 수탁자: Cloudflare, Inc.
  • 위탁 업무: 사용자가 전송한 진단 정보의 저장·보관 및 자동 삭제 처리

위 위탁 목적 외에는 진단 정보를 제3자에게 제공하지 않습니다.

8. 데이터 삭제

  • 보관함에서 개별 캡처를 삭제하면 해당 파일과 보관함 정보가 기기에서 삭제됩니다.
  • 앱을 제거하면 앱 데이터 폴더에 저장된 설정·보관함 데이터는 Windows의 앱 데이터 관리 방식에 따라 삭제되거나 정리될 수 있습니다. 다만 사용자가 직접 저장한 캡처 파일이나 사용자가 지정한 저장 폴더의 파일은 앱 제거 후에도 남을 수 있으며, 사용자가 직접 삭제할 수 있습니다.
