필요한 기능, 다 들어있습니다

캡처부터 주석, 녹화까지 - 별도 도구 없이 ClipShot 하나로.

빠른 캡처

영역·전체 화면·특정 창을 단축키 한 번으로. 멀티 모니터도 지원합니다.

Ctrl + Alt + C

강력한 주석 편집

사각형·화살표·텍스트·번호·형광펜·모자이크. 캡처 직후 바로 편집하세요.

GIF · 동영상 녹화

영역 또는 전체 화면을 MP4·GIF로 녹화하세요. MP4 동영상에는 시스템 사운드까지 함께 담을 수 있습니다.

Ctrl + Alt + R

화면 위 즉시 편집

캡처하자마자 그 자리, 화면 위에서 바로 편집. 별도 창을 띄우지 않아요.

텍스트 추출 (OCR)

캡처 속 글자를 텍스트로 추출하세요. 한국어·영어를 지원하며, 결과를 확인·수정한 뒤 복사할 수 있습니다.

민감정보 가리기

모자이크·블러로 가린 뒤 안심하고 공유하세요.

GIF 품질 설정

용도에 맞게 GIF 품질을 선택해 가볍게 만들거나 더 선명하게 저장할 수 있습니다.

저장·복사 선택

캡처 후 파일로 저장하거나 클립보드에 복사해 바로 붙여넣을 수 있습니다.

캡처 보관함 · 본문 검색

복사하거나 저장한 캡처를 자동으로 보관합니다. 타입·기간·앱으로 찾고, 이미지 속 글자까지 검색하세요.

최근 캡처

최근 캡처가 메인 화면에 바로 보입니다. 클릭해서 미리보기·복사·편집하세요.

단축키 커스터마이징

캡처·편집 단축키를 내 손에 맞게 자유롭게 설정.

가볍고 빠름

Rust + Tauri 기반 네이티브 앱. 시스템 자원을 거의 쓰지 않고 즉시 실행됩니다.

한국어 · 영어

OS 언어를 자동 감지하고, 설정에서 한국어/영어를 직접 선택할 수 있습니다.

지난 캡처를 다시 찾는 가장 쉬운 방법

복사하거나 저장한 캡처를 자동으로 모아두고, 제목·필터·검색으로 빠르게 다시 찾으세요.

자동 보관

복사하거나 저장한 캡처를 자동으로 모아둡니다.

제목으로 정리

캡처 제목을 바꿔 나중에 찾기 쉽게 정리할 수 있습니다.

타입·기간·앱 필터

이미지, 동영상, GIF와 날짜, 출처 앱 기준으로 빠르게 좁혀볼 수 있습니다.

이미지 속 글자 검색

캡처 안의 텍스트까지 검색해 원하는 화면을 다시 찾을 수 있습니다.

이럴 때 ClipShot이 편합니다

캡처 한 번이 이렇게 쓰여요.

버그 리포트

화살표·번호·텍스트 등 다양한 주석으로 개발자에게 정확히 전달.

피드백 공유

디자인·문서 위에 바로 의견을 남겨 공유.

영상 시연

동작을 GIF·동영상으로 담아 움직임 그대로 보여주기.

자료 보관·검색

영수증·정보 화면을 모아두고, 필요할 때 검색해 다시 꺼내기.

내 캡처는, 내 PC에만

캡처·녹화·보관함 모두 로컬에 저장됩니다. 클라우드로 올라가지 않아요.

내 PC에 저장

모든 캡처가 내 PC에 저장됩니다. 외부 서버로 전송되지 않아요.

계정·로그인 없음

가입도 로그인도 필요 없습니다. 설치하고 바로 쓰세요.

광고·추적 없음

광고도 사용자 추적도 없습니다.

Microsoft Store 설치

Microsoft Store에서 설치하고, 업데이트도 안전하게 받을 수 있습니다.
