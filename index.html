빠른 캡처

영역·전체 화면·특정 창을 단축키 한 번으로. 멀티 모니터도 지원합니다.

Ctrl + Alt + C

강력한 주석 편집

사각형·화살표·텍스트·번호·형광펜·모자이크. 캡처 직후 바로 편집하세요.

GIF · 동영상 녹화

영역 또는 전체 화면을 MP4·GIF로 녹화. 시스템 사운드까지 함께 담습니다.

Ctrl + Alt + R

캡처 보관함 · 본문 검색

모든 캡처가 자동으로 보관됩니다. 타입·기간·앱으로 거르고, 이미지 속 글자까지 검색하세요.

메인 화면 최근 캡처

최근 캡처가 메인 화면에 바로 보입니다. 클릭해서 미리보기·복사·편집하세요.

화면 위 즉시 편집

캡처하자마자 그 자리, 화면 위에서 바로 편집. 별도 창을 띄우지 않아요.

민감정보 가리기

모자이크·블러로 가린 뒤 안심하고 공유하세요.

복사해서 바로 붙여넣기

클립보드로 복사해 그림판·채팅 어디든 실제 크기 그대로 붙여넣기.

단축키 커스터마이징

캡처·편집 단축키를 내 손에 맞게 자유롭게 설정.

가볍고 빠름

Rust + Tauri 기반 네이티브 앱. 시스템 자원을 거의 쓰지 않고 즉시 실행됩니다.

한국어 · 영어

OS 언어를 자동 감지하고, 설정에서 한국어/영어를 직접 선택할 수 있습니다.

무료

Microsoft Store에서 무료로 받으세요. 광고도, 결제도 없습니다.

100% 로컬 저장

모든 캡처가 내 PC에만 저장됩니다. 외부 서버로 전송되지 않아요.
